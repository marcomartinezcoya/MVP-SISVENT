Instrucciones del Proyecto - SISVENT

## 🎯 Objetivo del Proyecto
Construir un sistema de gestión de inventarios moderno usando:

- Next.js (App Router)
- Tailwind CSS
- Supabase (a futuro)

El sistema debe ser:
- Moderno
- Minimalista
- Profesional (estilo SaaS)

---

## 🎨 Reglas de UI

- Seguir estrictamente el diseño definido en `guidelines.md`
- NO cambiar colores, tipografía ni espaciados
- Mantener consistencia en todos los módulos

---

## 🧱 Reglas de Arquitectura

- Usar estructura modular por funcionalidad

Ejemplo:

- /app/productos
- /app/compras
- /app/ventas

- /components/ui
- /components/layout
- /components/modules

---

## 🧩 Reglas de Componentes

- Reutilizar componentes UI (botones, cards, inputs)
- Evitar duplicación de componentes
- Crear componentes pequeños y reutilizables



## 🎯 Reglas de UX

- La información importante debe verse primero (cards)
- Las acciones deben ser claras (botones, iconos)
- Evitar sobrecargar la interfaz
- Mantener diseño limpio y rápido

---

## 🚫 Restricciones

- NO usar librerías innecesarias
- NO romper la consistencia del diseño

---

## ⚡ Enfoque de Desarrollo

- Mantener código limpio y escalable
